# **App Name**: Cafe Didar (کافه دیدار)

## Core Features:

- Luxury Dynamic Menu: Multi-category interactive menu featuring dark glass cards, product imagery, and elegant smooth transitions.
- Hidden Management Portal: Integrated dashboard for admins to manage menu items, prices, and photo uploads, accessible via hidden password input.
- AI Menu Stylist: A tool powered by generative AI that helps admins write evocative, high-end Persian descriptions for new menu offerings.
- Local Persistence Engine: A custom data layer that handles orders, loyalty points, and feedback using localStorage for Zero-DB offline resilience.
- Loyalty Progression System: Account tracking via phone numbers to manage points, featuring gold membership card visual progress animations.
- Star Feedback Suite: Customer feedback interface with animated star ratings and gold highlights for top reviews.
- Dynamic QR Generator: In-app utility to generate and print table-specific QR codes (1-13) linked to custom URL parameters.

## Style Guidelines:

- Primary color: Gold (#D4A853) evoking Persian luxury and high-end hospitality.
- Background color: Dark Espresso (#1C0F0A), providing a sophisticated, deep canvas for content.
- Accent color: Deep Umber (#753622) for semantic contrast and card detailing.
- Font recommendation: 'Vazirmatn' for a specialized, clean, and legible Persian typeface. Note: currently only Google Fonts are supported.
- Mobile-first single-page architecture with state-controlled views and no external routing artifacts.
- Gold-filled glyphs with subtle glowing borders for active navigation and bottom tab bars.
- Staggered CSS animations for card loading and bounce-scale effects on cart badges and buttons.
